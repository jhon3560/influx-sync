| bench/loadgen | worker 写失败退出后主循环阻塞永久挂起 | ✅ done 通道 + break send + wg.Wait + 错误退出 |

### 深度复核（未发现新问题）

- **N16 预取正确性**：① 槽游标与当前游标不符时丢弃同步重查（防游标未推进时
  复用过期结果——零丢失兜底）；② append/cursor 失败即置 nil 作废预取；③ 预取
  窗口 ≤ MaxWindow 门控（切片路径不预取），**消费轮窗口有界不变量保持**；④
  slot.end > slot.cursor 由 launch 检查保证，消费时"新鲜 end ≤ cursor 提前返回"
  与"槽窗口越过当前水位"互斥（推演无矛盾路径）；⑤ 预取查询复用 Run ctx，
  关停时随 ctx 取消返回错误，消费轮无永久阻塞。
- **N14 增长语义**：空窗与稀疏窗（< 目标）均驱动翻倍、稠密（≥ 目标）复位；
  切片路径空片直接推进游标（空查询⟹区间无数据论证沿用 V1.7.1，含快路径
  Filter 兜底）；post-filter 归零的片走稀疏分支 appendFrames(空)=nil 后推进游标
  ——快路径已全量转发的区间正确跳过。
- **N15 自愈**：查询失败复位增长 → 下轮回基础窗口，避免大窗口持续失败停滞；
  与预取交互正确（失败轮不启动预取）。
- **N12 修复**：与真机实测布局一致；`len(row) < 4` 守卫正确。
